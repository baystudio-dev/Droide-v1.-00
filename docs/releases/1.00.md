# Droide 1.00

Droide 1.00 brings editing, project management, a Linux terminal, Git, browser previews, extensions, and AI agents to Android in a single workspace.

## Highlights

- A tabbed editor with language services, navigation, formatting, and recovery drafts.
- File and folder search, move, import, and export workflows.
- A persistent Linux workstation with development runtimes installed on demand.
- Built-in and external agents with visible tool activity, code diffs, reusable skills, and MCP connections.
- Browser actions and provider-backed image generation within agent workflows.
- Portrait and landscape workbench layouts with collapsible panels.

## Install

Download `Droide-1.00-release.apk` from [the release page](https://github.com/baystudio-dev/Droide-v1.-00/releases/tag/v1.00).
